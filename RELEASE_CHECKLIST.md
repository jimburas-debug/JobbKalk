# Sjekkliste før offentlig utgivelse

- [ ] Kjør alle formeltester på Windows 10 og Windows 11.
- [ ] Gjennomgå hver formel med fagperson, spesielt elektro og nyttelast.
- [ ] Test norsk komma og punktum som desimalskilletegn.
- [ ] Test ved 100 %, 125 %, 150 % og 200 % skjermskalering.
- [ ] Test bærbar EXE på en PC uten installert .NET.
- [ ] Test installasjon, oppgradering og avinstallering med standardbruker.
- [ ] Legg til ferdig programikon og utgiverinformasjon.
- [ ] Kodesigner begge EXE-filer for å redusere SmartScreen-advarsler.
- [ ] Kjør antivirus- og omdømmekontroll på de signerte filene.
- [ ] Fastsett lisens, brukervilkår og versjonsnummer.
- [ ] Lag en enkel brukerveiledning og supportadresse.
